# Site Baseline Configuration - Water Quality Network

Owner: network operator. Version v1.2, 2026.

## Conductivity operating band
Expected conductivity at Krishna River and Budameru Canal stations is 150 to 900 µS/cm at 25 °C, derived from 12 months of historical monitoring. Values outside the band trigger review. This is an operational baseline, not a regulatory limit.

## Water temperature
No regulatory limit is configured. Temperature is used as context for dissolved oxygen interpretation (oxygen solubility decreases as temperature rises).
